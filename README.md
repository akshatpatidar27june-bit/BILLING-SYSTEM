# StoryCreateEditor

Cinematic wedding films, reels, editing, enquiry, booking, and content management platform.

## Project

This repository is being used as the starting point for the StoryCreateEditor client website and its admin management system.

### Planned modules

- Cinematic public website
- Wedding film portfolio
- Reels showcase and publishing
- Services management
- Enquiry and booking system
- Shoot/event details
- Booking calendar
- Project management
- Testimonials
- Media library
- Deep website content management (CMS)
- Admin authentication and roles
- Notifications and activity history

## Development

The repository is intentionally starting clean. Architecture, database schema, UI, and application modules will be added incrementally.
